UPORA TRAVELS — WEBSITE DEMO BY UPORA

Files
- index.html: page content and sections
- style.css: layout, responsive styling, animations
- script.js: mobile navigation, hide/reveal sticky header, scroll reveals, package filters, testimonial controls and enquiry form demo

Run locally
1. Extract the ZIP.
2. Open index.html in Chrome/Edge, or open the folder in VS Code and run it with Live Server.
3. Internet access is needed for Google Fonts and remote Unsplash photos.

Demo content notice
- Upora Travels is a fictional demo brand created for a sales presentation.
- OMR, Chennai is sample location copy.
- +91 99 99 99 99 99 is a deliberately non-operational placeholder number, not a verified contact number.
- Package prices are illustrative starting prices, not offers or verified quotes.
- Testimonials are labelled sample guest testimonials and are fictional.
- Photos are remotely loaded from Unsplash and are illustrative.
- The form only opens an email draft (without a recipient address); it does not submit, store, or send data. Configure a real email address or form backend before launch.

Built with plain HTML, CSS and JavaScript. No build step required.
